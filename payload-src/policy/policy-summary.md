# IRIS 설치기가 지키는 약속 — 사람이 읽는 요약

이 글은 **설치기가 무엇을 하고 무엇을 하지 않는지**를 약속으로 적은 것이다. 컴퓨터를 잘 몰라도 읽을 수 있게 썼다. 전문용어는 처음 나올 때 괄호로 풀이한다.

한 줄 요약: **설치기는 당신의 기존 자료를 하나도 지우지 않으며, 거의 모든 것을 `C:\IRIS` 폴더 안에서만 한다.**

---

## 1. 무삭제 계약 — 지우지 않는다

설치기는 다음을 **삭제하거나 덮어쓰지 않는다.** 이건 선택 사항이 아니라 설계된 약속이고, 설치가 끝난 뒤 검사로 확인한다.

| 지키는 것 | 무슨 뜻인가 |
|---|---|
| 당신의 문서·사진·내려받은 파일 | 설치기는 이 파일들을 읽지도, 옮기지도 않는다 |
| 이미 깔려 있는 프로그램 | 이미 있는 Node·Python·Git 등을 지우거나 판을 바꾸지 않는다. 설치기는 **자기가 동봉한 사본**을 자기 폴더 안에서 쓴다 |
| 이미 쓰던 비서 설정·대화 기록 | 기존 설정 파일이 있으면 **합치고**, 통째로 바꾸지 않는다 |
| 기존 `C:\IRIS` 자료 | 이미 IRIS를 쓰고 있었다면 만든 폴더와 파일을 그대로 두고 빠진 것만 채운다 |
| 코드 저장소의 `.git` | 버전 기록은 손대지 않는다 |

**실패해도 지우지 않는다.** 설치 도중 무언가 실패하면 그 자리에서 멈추고 무엇이 막혔는지 알려 준다. 이미 만들어 둔 것을 되돌리려고 지우는 일은 하지 않는다.

---

## 2. 묻는 것과 알아서 하는 것

설치기는 **필요한 것만, 한 번에 하나씩** 묻는다. 경계는 이렇다.

### 물어보는 것 (당신이 정한다)

1. **어떤 구독을 쓸지** — Claude, ChatGPT, 또는 둘 다.
2. **어떤 작업 폴더를 만들지** — 역할(예: 교사·연구자·사업가) 한 개 이상. 분야·프로젝트는 원하면 추가.
3. **이대로 설치할지** — 만들 폴더 목록과 구독을 요약해 보여 준 뒤 시작 단추 한 번.
4. **구독 로그인** — 브라우저에서 당신이 직접 로그인한다. 이건 사람만 할 수 있어서 대신 해 줄 수 없다.

### 묻지 않고 알아서 하는 것

- 동봉한 프로그램 풀기, 폴더 뼈대 만들기, 설정 파일 쓰기, 검사하기.
- 단계(S)·세부 작업(T) 폴더와 태그는 **묻지 않고 미룬다.** "그 일이 실제로 시작될 때 비서가 만든다"고 기록만 해 둔다. 아직 하지도 않을 일의 폴더를 미리 만들어 어지럽히지 않기 위해서다.
- 폴더 번호 매기기(`R01`, `R02` …)와 이름 형식 맞추기.

### 절대 하지 않는 것

- **당신 대신 결제·구매·구독 신청을 하지 않는다.** 설치기는 돈을 쓰지 않는다.
- 당신의 파일을 인터넷으로 보내지 않는다. 설치기에는 사용 기록 수집(텔레메트리) 기능이 없다.
- 백신·방화벽·윈도 보안 설정을 끄지 않는다.

---

## 3. 바탕화면 금지 — 바로가기 하나뿐

설치기는 **바탕화면에 파일·임시물·캐시를 쓰지 않는다.** 바탕화면에 남기는 것은 「IRIS」 바로가기 **딱 하나**다. 설치가 끝난 뒤 검사에서 "바탕화면 쓰기 0건"을 확인하고, 하나라도 있으면 설치를 실패로 본다.

비서(에이전트)도 같은 규칙을 따른다. 만든 결과물은 바탕화면이 아니라 그 일에 해당하는 IRIS 안 폴더에 저장하고, 응답에 전체 경로를 적어 준다.

---

## 4. IRIS 폴더 밖에 손대는 곳 — 전부 세 가지

설치기가 `C:\IRIS` **밖**에 쓰는 것은 아래 세 가지가 전부다. 이 목록에 없는 곳에 쓰면 설치기가 스스로 실패로 판정한다.

| 밖에 쓰는 것 | 왜 필요한가 | 어떻게 되돌리나 |
|---|---|---|
| **PATH** (명령을 어디서든 부를 수 있게 하는 목록) | IRIS가 동봉한 프로그램을 창에서 부르기 위해 | 윈도 「환경 변수 편집」에서 IRIS 줄만 지우면 된다 |
| **사용자 환경변수 몇 개** | 비서가 자기 설정 폴더와 중계기 주소를 찾기 위해 | 같은 화면에서 `IRIS`·`CLAUDE_`·`CODEX_`로 시작하는 항목만 지우면 된다 |
| **바탕화면 「IRIS」 바로가기** | 두 번 눌러 여는 입구 | 그냥 삭제하면 된다 |

이 세 가지는 모두 **당신 계정에만** 적용된다. 컴퓨터 전체 설정(다른 사용자 계정, 시스템 설정)은 바꾸지 않으므로 관리자 권한도 필요하지 않다.

임시 파일과 설치 기록은 `%LOCALAPPDATA%\IRIS-Installer\`(윈도가 정해 둔 당신 계정의 임시·기록 폴더)에 남는다.

---

## 5. "대기(pending)"라는 말의 뜻

설치가 끝난 화면에 어떤 기능이 **대기**로 적혀 있을 수 있다. 이건 **고장이 아니다.** "지금은 못 하지만, 필요한 것이 생기면 바로 된다"는 뜻이다. 없다고 흉내 내지 않고 정직하게 알려 주는 것이 규칙이다.

| 대기로 표시되는 것 | 무엇이 없어서인가 | 채우는 법 |
|---|---|---|
| 엑셀·워드·파워포인트 자동화 | 그 PC에 Microsoft Office가 없음 | Office를 설치하면 다음 실행부터 자동으로 살아난다 |
| 한글(HWP/HWPX) 자동화 | 한컴 오피스가 없음 | 한컴 오피스를 설치하면 된다 |
| 브라우저 조작 | Microsoft Edge가 없음 | Edge를 설치하면 된다 |
| 이미지 생성 | 이미지용 열쇠(API 키)가 아직 없음 | 나중에 열쇠를 금고에 넣으면 된다 |

대기는 **기록으로 남는다.** 비서는 그 기능이 필요한 일을 만나면 "지금은 ○○이 없어서 못 합니다"라고 먼저 말한다.

> **참고 — 열쇠(API 키)란?** 어떤 서비스가 "이 사람이 맞다"고 알아보게 해 주는 긴 문자열이다. IRIS는 열쇠를 **금고 파일 한 곳**에만 보관하고, 지침·코드·기록 어디에도 원문을 적지 않는다.

---

## 6. 다시 실행해도 안전하다

설치가 도중에 멈췄거나(인터넷이 끊겼거나 창을 닫았거나) 나중에 다시 켜고 싶을 때, **그냥 다시 실행하면 된다.**

```text
① 다시 실행 — 설치기가 이전 기록(영수증)을 읽는다
    ↓
② 이미 끝난 단계는 건너뛴다 — 다시 풀거나 다시 쓰지 않는다
    ↓
③ 멈췄던 단계부터 이어서 한다 — 처음 답한 내용은 다시 묻지 않는다
```

두 번 실행해도 결과가 달라지지 않는지(같은 파일이 그대로인지)를 설치기 스스로 검사한다. 이미 답한 질문은 저장돼 있어서 다시 묻지 않고, 바꾸고 싶으면 그때 고칠 수 있다.

---

## 7. 기록은 어디에 남나

무슨 일이 있었는지 확인하고 싶거나 도움을 요청할 때 볼 곳이다.

| 무엇 | 어디에 |
|---|---|
| 설치 진행 기록(로그) | `%LOCALAPPDATA%\IRIS-Installer\bootstrap.log` |
| 설치 결과 요약(사람이 읽는 보고서) | IRIS 폴더 안 `_agent\setup\설치보고-<날짜>.md` |
| 어떤 부품이 어떤 판으로 깔렸는지(영수증) | IRIS 폴더 안 `_agent\setup\package-receipt.json` |
| 당신이 답한 선택 | IRIS 폴더 안 `_agent\setup\decisions.json` |
| 설치기가 비서에게 넘기는 인수인계 | IRIS 폴더 안 `_agent\setup\handoff.json` |

이 기록은 **당신 컴퓨터 안에만** 남는다. 아무 데도 전송되지 않는다. 문제를 알려 줄 때 쓰라고 만든 진단 파일에는 사용자 이름과 경로가 가려져 있고, 보낼지 말지는 전적으로 당신이 정한다.

---

## 8. 설치를 그만두고 싶으면

- 설치 **전·도중**: 창을 닫으면 그 자리에서 멈춘다. 만들어진 것은 그대로 남고, 나중에 다시 실행하면 이어서 한다.
- 설치 **후**: `C:\IRIS` 폴더를 통째로 지우고, 위 4절의 세 가지(PATH·환경변수·바탕화면 바로가기)를 되돌리면 설치 전 상태가 된다. 설치기가 그 밖의 곳을 건드리지 않았기 때문에 이것으로 끝이다.
