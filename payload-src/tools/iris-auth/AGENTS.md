# iris-auth — 로그인 열쇠 만료 감시·1년 열쇠 발급 도구

중계기 계정 열쇠와 IRIS 클로드코드 자체 열쇠의 **만료일만** 모아 보고(`status.mjs`), 만료 전에 알리고, IRIS용 1년 열쇠(`claude setup-token`과 같은 요청: 권한 `user:inference`, `expires_in` 31536000)를 발급한다(`longkey.mjs`). IRIS 창(설정 → 계정·보안 → 로그인 열쇠)이 이 폴더를 찾아 30분마다 부르고, 갱신 단추도 이 도구를 실행한다.

- 열쇠 값은 화면·로그·상태 파일에 절대 쓰지 않는다. 상태 파일 `~\.config\iris-auth-status.json` 에는 이름·만료 시각·단계만 담는다.
- 1년 열쇠 파일 = `<CLAUDE_CONFIG_DIR>\secrets\iris-cli-token.json`. IRIS 창이 세션을 띄울 때 `CLAUDE_CODE_OAUTH_TOKEN` 으로 넣는다.
- **두 자리 쓰기**(`longkey.mjs --account <중계기 계정 이름> --also-iris`): 승인 한 번으로 받은 1년 열쇠를 중계기 계정 줄과 위 1년 열쇠 파일에 함께 넣는다. 설치 화면의 「1년 열쇠 받기(권장)」 카드가 부른다. 순서 = 중계기 계정 줄 → 1년 열쇠 파일 → 다시 읽기 부탁. 300일보다 짧은 열쇠 · 승인한 계정이 다른 열쇠는 어느 자리에도 쓰지 않는다. 한 자리만 써져도 그 자리에서 유효하므로(1년 열쇠는 쓸 때마다 바뀌지 않는다) 되돌리지 않고 `RESULT` 에 자리별 결과(`relay` · `iris` = `ok` | `skipped` | `failed`)만 싣는다. 중계기 설정은 그 계정 한 줄만 바꾸며, 바꿔 끼우기 직전에 다시 읽어 그 줄이 달라졌으면 포기한다(설정 전체를 사본으로 되돌리지 않는다). 이 길의 출력에는 계정 이름을 싣지 않는다. 한 자리에서 폐기하면 다른 자리도 함께 끊긴다 — 다시 받으면 된다. 시험 = `tests\also-iris.test.mjs`(가짜 열쇠 교환 · 임시 폴더).
- 클로드 세션이 시작될 때도 한 번 부른다(`status.mjs --hook`, 설치 패키지가 건 세션 시작 훅): IRIS 열쇠가 곧 끝나거나 끝났을 때만 한 줄을 낸다. 이 PC 의 파일을 **읽기만** 한다 — 상태 파일은 쓰지 않는다(상태 파일과 알림 기록은 IRIS 창의 점검 한쪽만 쓴다: 둘이 번갈아 쓰면 알림 기록이 옛 값으로 되돌아가 같은 알림이 되풀이된다). 실패해도 세션을 막지 않는다.
- 판정 규칙은 `lib.mjs` 한 곳(순수 함수, 시험 = `node --test "tests/*.test.mjs"`).
- 설치 패키지가 넣은 부품이다 — 고치려면 설치 패키지 원본을 고쳐 새 판으로 낸다(이 폴더를 손으로 고치면 다음 업데이트가 덮는다).
