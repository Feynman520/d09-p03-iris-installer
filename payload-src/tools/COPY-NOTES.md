# 이 폴더의 사본이 개발 PC 원본과 일부러 다른 점

이 폴더의 도구는 개발 PC 의 도구(`<IRIS 루트>\_agent\claude\tools\…`)를 **일반화한 사본**이다. 설치 패키지는 이 사본만 싣는다(빌드가 개발 PC 를 읽지 않는다).

원본이 바뀌면 **원본으로 덮지 않는다.** 사본을 기준으로 기능 변경만 옮기고, 아래 목록의 차이는 그대로 둔다. 차이를 새로 만들면 이 목록에 한 줄을 더한다. 이 파일은 부품에 실리지 않는다(부품 폴더 밖에 있다).

## iris-auth (로그인 열쇠 감시 도구)

| 자리 | 사본 | 원본 | 왜 |
|---|---|---|---|
| `use-longkey.ps1` · `use-longkey.test.ps1` · `check-hidden.vbs` | 없음 | 있음 | 개발 PC 의 예약 작업용이다. 설치 PC 에서는 IRIS 창이 30분마다 부른다. |
| `status.mjs` 사람용 출력의 꼬리 글 | "IRIS 창은 1년 열쇠 사용" | "IRIS 창·예약 작업은 …" + 예약 작업 주석 | 설치 PC 에는 그 예약 작업이 없다. |
| `status.mjs` `--hook` 주석 | "중계기 계정은 IRIS 창과 대시보드가 알린다" | 개발 PC 의 다른 세션 훅 이름 | 그 훅은 싣지 않는다. |
| `lib.mjs` 갱신 방법 주석 | 계정 표시 없음 | 실측한 계정 표시가 있음 | 공개 저장소에 계정 이름을 넣지 않는다. |
| `tests\*.test.mjs` 의 예시 이름 | `a@localhost` 꼴 | 이메일 모양의 예시 | 정화 규칙이 이메일 모양을 막는다(예시라도). |
| `status.mjs` `writeStatus` | 이름 바꾸기가 거절되면 자기 임시 파일을 지운다 | 지우지 않는다 | 여럿이 겹쳐 돌 때 진 쪽의 `<상태 파일>.<번호>.tmp` 가 남는 것을 시험이 잡았다(2.0.65). **원본에도 옮길 것** — 옮기면 이 줄을 지운다. |
| `AGENTS.md` | 설치 PC 사용자용 설명(IRIS 창이 부른다 · 부품이라 손으로 고치지 않는다) | 개발 PC 운영 메모(사고 이력 · 예약 작업 연결처) | 읽는 사람이 다르다. |

옮긴 기능 변경(2.0.65): `lib.mjs` 항목의 `health` 칸 · `status.mjs` 의 `--skip-provider`(공급자 빼기)와 알림 기록 칸 분리(`notify` · `notify_skip_*`) · 상태 파일을 쓸 때 프로세스마다 다른 임시 파일 이름 · 시험 `tests\health.test.mjs` · `tests\skip-provider.test.mjs`.
