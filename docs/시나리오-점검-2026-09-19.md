# 구독 시나리오 전면 점검 — 클로드만 · 코덱스만 · 둘 다 (2026-09-19)

사용자 요청(피드백 11번): "코덱스 단독이 문제가 많다 — 세 시나리오를 전면 점검". 설치 ⑥·⑦ 과 IRIS 창의 첫 실행이 **구독 선택(`choice.subscriptions`)에 따라 갈라지는 자리**를 전부 찾아, 각 시나리오에서 무엇이 일어나는지·어디까지 확인됐는지를 적는다.
확인 등급: **코드**(코드를 읽어 분기가 맞음) · **시험**(단위 시험이 그 분기를 고정) · **실기**(실제 PC·VM 에서 봄) · **미확인**.

## 2. 코덱스만 시나리오에서 2.0.19 까지 실제로 벌어진 일(연쇄)

```text
① ⑥ 검사 13 = 대기(중계기 없음) → CA 번들 안 만듦
    ↓
② ⑦ 로그인·중계기 시작 → 아무도 검사 13 을 다시 안 잼 (2.0.20 에서 고침)
    ↓
③ codex.cmd 의 SSL_CERT_FILE 이 없는 파일 → 코덱스 TLS 실패 또는 직행 → 대시보드 활동 0
    ↓
④ 첫 세션: 신뢰 물음(선답 누락) + 샌드박스 물음(elevated 시도) → 카드 클릭 안 됨(키 한 덩어리)
    ↓
⑤ IRIS 창은 브라우저 탭(electron.exe 미동봉) — 이건 세 시나리오 공통
```

## 4. 실기 순서(사용자)

1. 집 데스크탑(코덱스만): 2.0.20 신규 설치 → ⑦ 화면 "검사 13 … 통과 · CA 번들" 행 확인 → 코덱스 세션 1건 → 한도 서랍 활동. 실패하면 「개발자에게 신고하기」.
