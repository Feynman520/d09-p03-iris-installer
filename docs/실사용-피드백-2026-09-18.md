## 2. 설계 결정이 필요한 것 — "이미 다른 TeamClaude 가 3456 을 쓰는 PC"

관측: 전역 npm TeamClaude 1.2.1(기존 Claude 계정 5개)이 3456 을 점유 → 설치기는 200 만 보고 "연결됨"으로 기록 → 대시보드는 동봉본(1.1.16+IRIS 패치) 기준
화면이라 전역본 응답과 어긋남, Codex 는 TeamClaude 를 경유하지 않음.

선택지:
- **A(권고) IRIS 동봉 중계기로 통일** — 설치기가 3456 의 주인이 동봉 node·동봉 entry 가 아니면 멈추고 알린다: "다른 TeamClaude 가 3456 을 쓰고 있습니다.
  IRIS 것으로 바꾸려면 [기존 계정 가져와서 교체] / 그대로 두려면 [건너뛰기(코덱스 연결·대시보드 제한)]". 교체 = 기존 설정 파일의 계정을 IRIS 설정으로
  **복사(삭제 없음)** → 전역본을 `stop` → 동봉본 `start`. 되돌리기 가능.
- B 현행(200 이면 재사용) 유지 + 화면에 "다른 실행본" 경고만.
- C 포트를 나눔(IRIS 는 다른 포트) — Face·심(shim)·`ANTHROPIC_BASE_URL` 전부 3456 고정이라 큰 변경.
