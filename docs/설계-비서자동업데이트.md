# 설계 — 설치 PC의 클로드·코덱스 자동 업데이트 (2.0.45, 2026-10-16)

> 계기(2026-10-16 사용자): "IRIS 패키지에 클로드랑 코덱스 각각 자동 업데이트 기능을 넣어야겠어. 너의 추천대로 끝까지."
> 조사 결과: 설치 PC의 클로드코드는 설치 때 판(2.1.272, 9/15 잠금)에, 코덱스는 zip 동봉 판(0.154.0, 9/10 잠금)에 멈춰 있었다.
> ⓐ 클로드는 `tools\claude\<판>\claude.exe` 를 전달자 `claude.cmd` 가 가리키고, IRIS 업데이트는 `claude.cmd` 가 **없을 때만** 채운다.
> ⓑ 코덱스는 zip 의 잠금 판이 한 번도 오르지 않았고, IRIS 창은 코덱스의 "Update available" 물음에 늘 「Skip」을 누른다.
> 개발 PC 는 자기만의 훅(`codex-autoupdate.ps1`·클로드 `autoUpdates`)으로 최신을 따라가고 있어 차이를 못 봤다.

## 1. 언제 도는가
- 바탕화면 「IRIS」 실행기(`<설치 폴더>\IRIS Face.cmd`)가 IRIS 창을 띄운 **뒤** `tools\updater\agents.mjs --kick` 을 부른다.
- `--kick` 은 0.1초 안에 끝난다: 마지막 확인이 6시간 안이거나 다른 확인이 돌고 있으면 그냥 끝, 아니면 창 없는 분리 자식(`--run`)을 띄우고 끝. IRIS 창 뜨는 속도에 영향 없음.
- 실행기는 relay 단계가 쓴다. 이미 설치한 PC 는 이 판(updater 부품이 바뀜 → `RELAY_PARTS`)으로 업데이트할 때 실행기가 다시 쓰여 이 줄이 들어간다.

## 2. 클로드코드
- 판 고르기 = 공식 **stable** 채널(`downloads.claude.ai/claude-code-releases/stable`). latest 보다 약 1주 늦은, 개발사가 "안정"이라 부르는 판 — 다른 학교 PC 에는 이것이 맞다(개발 PC 가 latest 로 먼저 밟는다).
- 받기 = `<판>/win32-x64/claude.exe`, 검증 = 같은 판 `manifest.json` 의 `platforms.win32-x64.checksum`(sha256). 설치기 출처 1과 같은 경로·같은 검증.
- 놓기 = `tools\claude\<새 판>\claude.exe`(임시 이름으로 받은 뒤 검증 통과 시 이름 바꿈) → `claude.exe --version` 이 새 판을 말하면 → 전달자 `claude.cmd` 를 새 판으로 **바꿔 쓰기**(임시 파일 → 이름 바꿈). 돌고 있는 세션은 옛 판 exe 를 그대로 쓰므로 끊기지 않는다.
- **전달자 모양(구현 중 실측으로 바뀜):** cmd.exe 는 자식이 끝난 뒤 배치 파일을 **바이트 위치로 다시 읽는다**. 옛 4줄 전달자를 세션이 도는 중에 바꿔 쓰면 그 세션이 끝날 때 `'/b' 은(는) … 아닙니다` 오류 + 종료 코드 1(실측). 그래서 전달자를 `"%~dp0<판>\claude.exe" %*&exit/b` + 공백 40칸 **한 줄**로 바꿨다 — 한 번에 해석되어 다시 읽을 것이 없고, 옛 4줄에서 처음 바뀔 때도 옛 읽기 위치가 공백에 떨어진다(판 문자열이 5글자 넘게 길어지지 않는 한). 실측 10건(1.0.0→10.20.300 · 2.1.272→2.1.292 · 2.1.99→2.1.100 · 짧아짐 · 2.1.292→2.1.301, 옛·새 모양 각각) 전부 종료 코드 유지·잡음 0. 설치기 출처 1(`installer/lib/online.mjs claudeForwarderText`)도 같은 글자로 맞췄다(시험이 두 곳을 묶음).
- 클로드 내장 자동 업데이트는 끈다: 설치기가 쓰는 `_agent\claude\settings.json` `env.DISABLE_AUTOUPDATER=1`(값이 없을 때만 — 사용자가 바꾼 값은 두는 기존 규칙). 내장 업데이트는 IRIS 밖(`%USERPROFILE%\.local`)에 쓰려 하기 때문이다.

## 3. 코덱스
- 판 고르기 = npm `@openai/codex` 의 `latest` 태그(`/@openai/codex/latest`, 약 1KB), 단 **이 PC 가 그 판을 처음 본 지 72시간 지난 판만**. 출시 시각(`time`)은 꾸러미 전체 문서(약 17.7MB, 실측)에만 있어 6시간마다 받기엔 커서, 처음 본 시각을 `agent-update.json codexSeen` 에 적어 센다 — 실제 출시보다 늦게 세는 쪽이라 안전하다. 지나지 않았으면 이번엔 건너뛰고 다음 확인에서 다시 본다. 갓 나온 판의 사고(중계기 호환 등)를 개발 PC 가 먼저 밟을 시간.
- 받기·검증 = 동봉 node 의 npm 으로 `npm install -g --prefix tools\codex-versions\<판> @openai/codex@<판>`(npm 이 sha512 integrity 검증). 설치기 npm 폴백과 같은 명령.
- 놓기 = 새 판 `codex.cmd --version` 확인 → `tools\codex\codex.cmd` 를 **전달자**(`"%~dp0..\codex-versions\<판>\codex.cmd" %*`)로 바꿔 쓰기. 판 폴더를 `tools\codex` **밖**에 두는 이유: IRIS 업데이트가 `tools\codex` 를 통째로 갈아 끼울 때 이미 받은 판이 `.prev` 로 쓸려 가지 않게. 그 경우 `codex.cmd` 가 동봉 판으로 돌아가는데, 다음 확인에서 받아 둔 판으로 다시 가리킨다(다시 받지 않음).
- IRIS 창의 「Skip」 자동 응답은 그대로 둔다(코덱스 자체 업데이트는 IRIS 밖 npm 전역에 깔려 하기 때문).

## 4. 안전장치
1. **실패는 조용히, 기록은 남김** — 망이 막혔거나(학교 방화벽) 검증이 틀리면 지금 판을 그대로 쓰고 `_agent\setup\agent-update.log` 에 한 줄, 상태는 `_agent\setup\agent-update.json`. 새 판이 `--version` 에 답하지 않으면 전환하지 않는다.
2. **한 번에 하나** — 잠금 파일 `_agent\setup\agent-update.lock`(30분 지나면 낡은 것으로 봄).
3. **디스크** — 남은 공간 2GB 미만이면 건너뜀.
4. **정리** — 판 폴더는 지금 판 + 직전 판 2개만 남기고 더 옛 판은 지운다(쓰는 중이라 못 지우면 다음에). 우리가 받은 프로그램 판일 뿐 사용자 자료가 아니다.
5. **끄기** — `agent-update.json` 에 `"disabled": true` 면 아무것도 안 함(문제 PC 응급 손잡이). 시험·연습은 `IRIS_AGENT_UPDATE=0` 으로 끈다.
6. **IRIS 폴더 밖 쓰기 0** — 임시 파일도 `_agent\setup\agent-update-tmp\` 안(npm 캐시 포함, 끝나면 지움).

## 5. 잠금표 원칙과의 관계
- zip 은 그대로 잠금 판으로 만든다(재현 빌드 유지). 설치 **뒤** 비서 두 개만 공식 검증(sha256·integrity)을 거쳐 새 판으로 올라간다 — 2026-10-16 사용자 결정에 따른 유일한 예외. 다른 부품(node·python·중계기·Face)은 계속 IRIS 업데이트로만 바뀐다.

## 6. 스스로 비판 → 반영
| 걱정 | 판단 |
|---|---|
| 새 코덱스가 중계기(MITM)와 안 맞으면 전 PC 동시 고장 | 72시간 지연 + 개발 PC(최신 자동) 선행 + `--version` 확인. 중계기 호환까지는 못 본다 → 응급 손잡이 `disabled`. 원격 정지(미러 latest.json)는 필요해지면 다음 판. |
| 230MB·300MB 내려받기가 수업 중 망을 잡아먹음 | 6시간에 한 번, 새 판 있을 때만. 클로드 stable 은 대략 주 1회. |
| 실행기 줄이 Face 를 늦춤 | `--kick` 이 Face 를 띄운 뒤 돌고 즉시 끝남. |
| 셸 템플릿(P02 와 바이트 일치 검사 ⑥)을 건드림 | 건드리지 않는다 — 심은 그대로 `tools\<도구>\<도구>.cmd` 를 부르고, 바뀌는 건 그 파일뿐. |
| 패키지 업데이트가 더 옛 판으로 되돌림 | 클로드는 IRIS 업데이트가 안 건드림. 코덱스는 다음 확인에서 다시 받은 판으로 복귀. |

- 실측 1회: 임시 루트에 2.1.272 전달자를 놓고 진짜 stable 받기(약 230MB) → 전환 확인.
