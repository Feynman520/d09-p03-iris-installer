# IRIS 설치 패키지 구현 계획 v2 (2026-09-15)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 서브에이전트에게 넘길 때 함께 전달할 루트 규칙: ① Anthropic API 프록시 우회 절대 금지(`ANTHROPIC_BASE_URL` 유지, 1토큰 프로브도 금지) ② 프로세스 종료는 PID로만(이름 기반 일괄 킬 금지, 3456·3457·3458은 PID를 알아도 종료 금지) ③ 한글·백슬래시가 든 파일은 Bash heredoc이 아니라 Write/Edit 도구로 쓴다(R-002) ④ 파이썬 인라인 실행은 `PYTHONUTF8=1`(R-010) ⑤ R/D/P 경로는 `ls`로 실제 이름을 복사해 쓴다(유령 폴더 금지) ⑥ 임시 파일은 세션 스크래치패드에만(R-015).

**Goal:** `IRIS-설치.zip`을 풀고 `IRIS-설치.cmd`를 두 번 클릭하면, 사람은 **구독 선택·작업 폴더 구성·구독 로그인**만 하고, 설치기 엔진이 **에이전트 없이** 실행기·에이전트·중계기·Face·메신저·도구·작업 폴더·지침·목록 카드까지 끝낸다. Face가 열리는 순간 이미 쓸 수 있다(설계 v2 0절).

**Architecture:** 겉옷(`IRIS-설치.cmd` → `bootstrap.ps1`, ASCII)이 무결성 검사 후 동봉 Node로 속옷(`installer/server.mjs`, 127.0.0.1:3460)을 띄운다. 속옷의 상태기계는 `precheck → locate → choice → structure → summary → setup → online → done`이며, `setup`은 `installer/setup/*.mjs` 엔진 9단계(인터넷 0), `online`은 `lib/online.mjs`(Claude Code 내려받기·로그인·중계기)다. 결과는 `_agent\setup\handoff.json` 한 파일로 Face에 넘긴다. zip은 공장(`build/`)이 `lock.json` 하나에서 도구까지 수집·캐시·정화·포장하고, 검사소(`verify/`)가 정적·재현성·압축엔진·네트워크 0·가상 영혼(e2e)으로 검증한다. 실제 환경은 VM 자동화(`verify/vm/`)와 시험 행렬 S01~S12로 검증한다.

**Tech Stack:** Node 24 ESM(설치기·엔진·공장·검사소), `node:test`, PowerShell 5.1(겉옷·훅), Windows `tar.exe`, Python 3.12(온톨로지 도구·문서 MCP; 임베드 판 가부는 T02가 정함), uv(오프라인 venv), IRIS-Face(P02, 2.7x), TeamClaude 1.1.16+IRIS 패치, VirtualBox 7 + Windows 평가판 ISO.

**Spec:** `docs\설계-v2.md`(2026-09-15 사용자 확정). 전판 `docs\설계.md`·`docs\구현계획.md`는 1층 결정·구현의 참고 원본.

- **질문은 두 가지**(D2-15): 구독 선택·작업 폴더 구성(+요약 확인). 선택형 질문 도구 없음, 화면 문구에 "TeamClaude" 이름 없음.
- **인터넷 경계**: `setup` 단계는 인터넷 0(`verify/offline.mjs`가 증명). 인터넷은 `online` 단계에서만(npm 저장소·claude.ai·chatgpt.com).
- **부품 잠금**: `lock.json` 하나가 유일한 진실 소스(D2-12). git=커밋, npm=판+integrity, wheel=requirements.lock 지문, url=SHA-256. `latest`·`main`·무버전 `npx` 금지. 새 판·지문은 T06에서 확정하고 이 문서에 다시 적지 않는다.
- **무삭제**: 기존 폴더·프로그램·사용자 자료를 삭제·덮어쓰지 않는다. 부품 교체는 `_agent\shared\tools` 안에서만, 이전 판 `.prev`. 기존 `C:\IRIS`(1.x)에는 자료 보존 이어 설치(S09).
- **원자 쓰기**: JSON은 임시 파일 → 이름 바꾸기. 영수증(`package-receipt.json`, `schema: 2`)·결정(`decisions.json`)·인수(`handoff.json`, `schema: 1`)·진단(`diagnostics.json`).
- **재실행**: 모든 단계 멱등. 실패는 단계 오류 코드(`E-PRECHECK`·`E-UNPACK`·`E-SKELETON`·`E-STRUCTURE`·`E-VENV`·`E-ADAPTERS`·`E-RELAY`·`E-ONTOLOGY`·`E-CHECKS`·`E-ONLINE-NET`·`E-ONLINE-CLAUDE`·`E-ONLINE-LOGIN`·`E-ONLINE-RELAY`)로 화면·로그에, 「다시 시도」는 그 단계부터. 고장 주입 `IRIS_INSTALLER_FAIL_AT=<단계id>`.
- **비밀 무접촉**: 영수증·로그·진단에 토큰·키·이메일 없음. 진단 파일은 사용자 이름·경로를 `<user>`로 가림.
- **ASCII 전용**: `IRIS-설치.cmd`·`bootstrap.ps1`·훅 `.ps1`은 ASCII(한글 금지). 한글 문구는 `ui/index.html`(UTF-8)·`payload/policy/*.md`에.
- **Face·대시보드·릴리스 도구 원본은 P03에서 고치지 않는다.** Face 변경 = P02 기능 브랜치(T21), 릴리스 도구 = `_agent\claude\tools\iris-release.mjs`(T22).
- **브랜치**: P03 `v2`(main에서 분기, T06에서 생성). 1~3층 초록 전 main 미병합. 커밋 메시지 끝 `Co-Authored-By:` 트레일러는 조정자가 지정하는 형태.
- **정화 규칙**: 저자 개인 핸들·이메일·사용자 프로필 하위 경로·실제 카드 ID·학교 도메인·요금제 이름표는 zip 어디에도 없어야 한다(지침 템플릿·프리셋·정책 문서·HWPX 양식 포함).
