# IRIS 삭제기 설계 (2.0.39)

> 2026-09-29 작성. 사용자 요청 원문: "패키지 압축을 풀고 IRIS 삭제 파일이 있어서 그걸 더블클릭하면 깨끗하게 IRIS를 삭제하도록 하고싶어. 물론 안내 문구도 보여주고 말이야." → 이어서 "너의 추천대로 끝까지 작업해서 배포까지 완료 후 보고해"(설계 결정 위임).
> 정본 관계: 설치기 전체 설계 = `설계.md`. 이 문서는 삭제기 하나만 다룬다.

## 한눈에

- zip을 풀면 `IRIS-설치.cmd` 옆에 **`IRIS-삭제.cmd`** 가 있다. 두 번 누르면 한국어 창이 떠서 무엇을 지우는지 설명하고, 고른 대로 지운 뒤 결과를 보여 준다.
- 기본값은 **"내 작업은 남기기"** — 사용자가 만든 폴더(R로 시작하는 폴더 등)는 `C:\IRIS-보관-YYYY-MM-DD` 로 옮기고 IRIS가 깐 것만 지운다. "전부 지우기"는 한 번 더 확인한 뒤에만.
- **설치 영수증이 있는 폴더만** 지운다. 영수증이 없는 폴더(이 개발 PC의 `C:\IRIS` 포함)는 어떤 경우에도 지우지 않는다.

## 1. 지우는 것과 남기는 것

설치기가 PC에 남기는 흔적은 폴더 안과 밖, 두 곳에 있다.

| 흔적 | 어디 | 삭제기의 처리 |
|---|---|---|
| IRIS 폴더(`C:\IRIS`) | 디스크 | 시스템 항목은 지우고, 사용자 항목은 고른 방식대로 |
| 사용자 PATH 한 칸(`…\_agent\shared\…\shims`) | `HKCU\Environment\Path` | IRIS 폴더 안을 가리키는 칸만 뺀다 |
| 환경변수 4개(`CLAUDE_CONFIG_DIR`·`CODEX_HOME`·`ANTHROPIC_BASE_URL`·`TEAMCLAUDE_CONFIG`) | `HKCU\Environment` | 값이 IRIS의 것일 때만 지우거나 설치 전 값으로 되돌린다 |
| 로그온 자동 시작 `IRIS relay` | `HKCU\…\CurrentVersion\Run` | 값이 IRIS 폴더를 가리킬 때만 지운다 |
| 바탕화면 바로가기 `IRIS.lnk` | 바탕화면(OneDrive 이동 포함) | 대상이 IRIS 폴더 안일 때만 지운다 |
| 설치기 작업 폴더 `%LOCALAPPDATA%\IRIS-Installer` | 사용자 프로필 | 이 PC에 다른 IRIS 설치가 하나도 안 남을 때만 지운다 |
| 실행 중인 IRIS 프로그램(중계기 3456·대시보드 3457·IRIS 창 3458·클로드·코덱스·MCP) | 메모리 | 지우기 전에 PID로 끈다 |

**시스템 항목**(IRIS가 만든 것, 항상 지움): `_agent`, `_ontology`, `_cleanup`, `_document-templates`, `_setup-guides`, `soul-state.json`, `AGENTS.md`, `CLAUDE.md`, `_cosmos.ico`, `desktop.ini`, `IRIS-온톨로지.md`, `IRIS-온톨로지-뷰.html`, `* Face.cmd`, 그리고 **비어 있는** `_trash`·`_backup`.

**사용자 항목**(그 밖의 전부): `R`로 시작하는 폴더, 이름 모를 파일·폴더, **내용이 있는** `_trash`·`_backup`.

- "남기기"면 사용자 항목을 `C:\<폴더이름>-보관-YYYY-MM-DD`로 **옮긴다**. 같은 날 폴더가 이미 있으면 **그 폴더를 이어 쓴다** — 일부 실패 뒤 다시 실행했을 때 남은 항목이 첫 실행이 옮긴 것 옆에 모인다(같은 날 다시 설치했다가 또 지울 때도 같다). 이름이 겹치는 항목만 번호를 붙이되, **폴더는 이름 전체 뒤에** 붙이고(`D02.01-작은 일 (2)`, `.agents (2)` — 이름 속 점에서 자르지 않는다) **파일은 확장자 앞에** 붙인다(`notes (2).txt`; 확장자뿐인 `.gitignore`는 `.gitignore (2)`). 그 이름이 파일이나 연결 폴더로 차 있을 때만 `-2`, `-3` …. 루트 `AGENTS.md`는 사용자가 규칙을 고쳤을 수 있어 보관 폴더에 **사본**을 둔다 — 이어 쓰는 보관 폴더에 이미 사본이 있으면 **내용이 같을 때만 건너뛰고**, 달라졌으면 `AGENTS (2).md`로 옆에 둔다(2.0.39 예행연습에서 발견: 고친 규칙이 조용히 빠지던 빈틈).
- 사용자 항목을 폴더 안에 그대로 두지 않는 이유: 영수증 없이 자료만 남은 `C:\IRIS`는 설치기가 "IRIS가 아닌 자료"(foreign)로 보고 재설치를 막는다(`server.mjs detectSoulMode`).
- **API 키·구독 로그인 정보·에이전트 기억·대화 기록**은 `_agent` 안에 있으므로 어느 방식이든 지워진다. 화면에 미리 밝힌다.
- 구독 해지는 PC에서 할 수 없으므로 마지막 화면에서 claude.ai·chatgpt.com에서 따로 하라고 안내한다.

## 2. 안전 장치

1. **영수증 문(門)** — `<폴더>\_agent\setup\package-receipt.json` 이 있고 JSON으로 읽혀야 지운다(1.x `schema 1`, 2.x `schema 2` 모두). 없으면 폴더를 한 글자도 건드리지 않는다.
2. **위험 위치 거부** — 드라이브 뿌리(`C:\`), `Windows`·`Program Files`·`ProgramData`·`Users`·사용자 프로필 자체, 그리고 **폴더 자체가 연결 폴더(junction·symlink)** 이면 거부한다.
3. **경로 비교는 뒤에 `\`를 붙여서** — `C:\IRIS` 뒤에 `\`까지 붙인 글자로 시작하는지 본다(`C:\IRIS-보관`이 `C:\IRIS`로 오인되지 않게).
4. **지우기는 `rd /s /q "\\?\경로"`** — 2026-09-29 실측: 읽기 전용·숨김·시스템 파일, 읽기 전용 폴더, 260자 넘는 긴 경로를 모두 지우고 **연결 폴더는 따라 들어가지 않는다**(바깥 표지 파일 보존). PowerShell 5.1 `Remove-Item -Recurse` 는 연결 폴더를 따라 들어가는 알려진 버그가 있어 쓰지 않는다.
5. **`rd`는 실패해도 0을 돌려준다**(실측: 열린 파일만 남기고 나머지를 지운 뒤 종료 코드 0). 그래서 결과는 **지운 뒤 실제로 남았는지**로 판정한다.
6. **옮기기가 실패한 사용자 항목은 절대 지우지 않는다**(실측: 안의 파일이 열려 있으면 폴더 옮기기가 "액세스 거부"로 실패). 그 항목은 제자리에 두고 결과에 알린다.
7. **영수증은 맨 마지막에** 지운다. 무엇이든 남았으면 영수증을 남겨, 다시 실행했을 때 문을 통과해 마저 지운다.
8. **자기 자신은 안 끈다** — 삭제기 PowerShell과 그 조상(IRIS-삭제.cmd를 돌리는 cmd 등)은 종료 대상에서 뺀다.
9. **자기가 지우는 폴더 안에서 돌지 않는다** — `IRIS-삭제.cmd`는 삭제기 파일을 `%TEMP%\IRIS-uninstall-<난수>`에 복사해 거기서 실행하고, 작업 폴더도 `%TEMP%`로 옮긴다. 설치본 안의 사본(`_agent\setup\installer\installer\IRIS-삭제.cmd`)에서 실행해도 안전하다. 실행부는 파일 **맨 끝의 `( … )` 한 덩어리**다 — cmd는 괄호 덩어리를 통째로 읽은 뒤 실행하므로 배치 파일이 지워져도 끝까지 돈다. 삭제기는 `start /wait /min` 으로 **자기 콘솔**에서 띄워 곧바로 숨긴다(사용자가 연 터미널을 숨기지 않고, 검은 창을 닫아도 삭제가 중간에 끊기지 않는다). 종료 코드는 덩어리 끝의 `cmd /d /c exit N` 으로 넘긴다 — 덩어리 뒤의 `exit /b N` 이나 다른 줄은 `cmd /c` 호출자에게 0을 돌려주는 경우가 있었다(실측). 각 갈래는 오류 코드를 판정한 **다음** 맨 앞에서 `(goto) 2>nul` 로 배치 문맥을 빠져나간다 — 그러지 않으면 덩어리가 끝난 뒤 cmd 가 이미 지워진 이 파일을 다시 열어 "지정된 경로를 찾을 수 없습니다"를 찍고 호출자에게 1 을 준다(2.0.39 실제 설치본 예행연습에서 발견, 검증기록 5-51).
10. **한 번에 하나만** — 이름 있는 뮤텍스(`Local\IRIS-uninstaller`)로 두 번째 실행은 "이미 실행 중" 안내 뒤 끝난다(종료 코드 4).

## 3. 화면

WinForms 창 하나(한국어 문구는 `installer\uninstall-ko.json`, UTF-8. 스크립트 `uninstall.ps1`은 ASCII만 — PowerShell 5.1이 BOM 없는 .ps1을 ANSI로 읽기 때문).

```text
① 안내 — 찾은 설치(여러 개면 고르기) · 지워지는 것 · [내 작업은 남기기(추천) / 전부 지우기] · [삭제 시작] [취소]
    ↓
② 확인 — "전부 지우기"일 때만: 지워질 내 자료 목록 + "되돌릴 수 없습니다" (기본 단추 = 아니요)
    ↓
③ 진행 — 단계 이름 + 진행 막대 + 기록 (창이 굳지 않게 긴 삭제는 별도 프로세스로)
    ↓
④ 결과 — 성공: 보관 폴더 경로 + [보관 폴더 열기] + 재설치 방법 + 구독 해지 안내
          일부 실패: 남은 것 목록 + 붙잡은 프로그램 이름 + [다시 시도] + "PC를 다시 시작한 뒤 한 번 더" + 기록 파일 경로
```

- 설치를 못 찾았는데 **흔적만 남은 경우**(사용자가 탐색기로 폴더를 직접 지운 PC): 환경변수 4개·PATH 칸·Run 값 `IRIS relay` 중 하나가 `X\_agent\…` 모양이고 `X`가 없으면 "IRIS 폴더는 이미 없고 설정 흔적만 남아 있습니다" → [흔적 지우기]. 없는 폴더 `X`를 가리키는 값·칸·바로가기만 지운다. 설치기 작업 폴더**만** 남은 경우는 흔적으로 치지 않는다 — 영수증을 아직 쓰지 않은, 지금 진행 중인 설치의 것일 수 있다.
- 아무 흔적도 없으면 "이 PC에서 IRIS를 찾지 못했습니다" + [닫기].
- 기록 파일: `%TEMP%\IRIS-uninstall-YYYYMMDD-HHMMSS.log`(UTF-8).

## 4. 순서

```text
① 프로그램 끄기 — IRIS 폴더 안 실행 파일 + 명령줄이 IRIS 폴더를 가리키는 스크립트 실행기 + 그 자식 중 콘솔 도구, PID로만
    ↓
② 자동 시작 빼기 — Run 값 `IRIS relay` (IRIS 폴더를 가리킬 때만)
    ↓
③ 환경변수 4개 — 지우거나 설치 전 값으로 되돌리기 (값 종류 REG_SZ/REG_EXPAND_SZ 보존)
    ↓
④ PATH 칸 빼기 — IRIS 폴더 안 칸만, 끝나면 설정 변경 알림(WM_SETTINGCHANGE) 방송
    ↓
⑤ 바탕화면 바로가기 — 대상이 IRIS 폴더 안인 .lnk 만
    ↓
⑥ 내 작업 옮기기 — "남기기"일 때 사용자 항목 → 보관 폴더
    ↓
⑦ 시스템 항목 지우기 — 루트 `+r` 해제 후 rd, 영수증(_agent\setup)은 마지막
    ↓
⑧ 설치기 작업 폴더 — 남은 IRIS 설치가 없을 때만 `%LOCALAPPDATA%\IRIS-Installer`
```

- **① 끌 대상**: 실행 파일이 `<루트>\` 아래(동봉 node·python·git·claude·codex 전부 여기 산다) / 이름이 스크립트 실행기(`node`·`python*`·`powershell`·`pwsh`·`cmd`·`wscript`·`cscript`·`bash`·`uv`)이면서 명령줄에 `<루트>\` 가 있음 / 위 프로세스의 자식 중 같은 실행기 이름 / 브라우저는 `--user-data-dir` 가 `<루트>\` 아래일 때만. **메모장·워드 같은 일반 창 프로그램은 끄지 않는다** — 그런 프로그램이 파일을 쥐고 있으면 Restart Manager(`lib\file-holders.ps1`)로 이름을 알아내 "이 프로그램을 닫고 [다시 시도]"라고 안내한다. 설치기 서버(3460)가 떠 있으면 `%LOCALAPPDATA%\IRIS-Installer\server.pid` 의 PID가 그 폴더 안 node일 때만 끈다.
- **③ 되돌리기 규칙**: 현재 값이 IRIS 값(`<루트>\` 를 가리키거나, `ANTHROPIC_BASE_URL` 이면 `http://127.0.0.1:3456`·`http://localhost:3456`)일 때만 손댄다. 영수증 `env.previous[이름]` 이 있고 그 값이 **IRIS 자신의 값이 아니면**(재설치 때 `previous` 에 IRIS 값이 적히는 경우가 있다 — `setUserEnv` 는 바뀌지 않아도 현재 값을 돌려준다) 그 값으로 되돌리고, 아니면 지운다. `ANTHROPIC_BASE_URL` 은 다른 IRIS 설치가 남아 있거나 `CLAUDE_CONFIG_DIR` 이 다른(있는) 폴더를 가리키면 그대로 둔다. 사용자가 설치 뒤 다른 값으로 바꾼 변수와 IRIS 이름이 아닌 변수는 건드리지 않는다.
- **종료 코드**(창 없이 `-NoUi` 로 돌릴 때·`IRIS-삭제.cmd` 가 그대로 넘김): 0 완료·흔적 정리·미리보기 / 1 일부 남음 / 2 거부·못 찾음·`-Mode all` 에 `-Yes` 없음 / 3 취소 / 4 오류·이미 실행 중.
- 새 값은 **이미 열려 있는 창에는 반영되지 않는다** — 결과 화면에 "열려 있던 터미널은 닫고 새로 여세요"라고 적는다.

## 5. 포장

- `installer\IRIS-삭제.cmd` → `build\pack.mjs` 가 zip 뿌리로 복사(CRLF 강제, `IRIS-설치.cmd` 와 같은 방식).
- `installer\uninstall.ps1`·`installer\uninstall-ko.json` 은 `installer\` 와 함께 들어간다.
- zip 뿌리 모양: `IRIS-설치.cmd · IRIS-삭제.cmd · 설치가 안 되면.txt · installer\ · lib\ · lock.json · payload\`.
- `verify\static.mjs` 에 검사 추가: zip 뿌리에 `IRIS-삭제.cmd` 가 있고 CRLF, `uninstall.ps1` 은 ASCII, `uninstall-ko.json` 은 UTF-8 JSON으로 읽히고 필요한 글쇠가 다 있음.
- README에 "지우기" 절, 홈페이지 설치 안내에 한 줄.
- **업데이트한 PC 의 사본에도 들어가야 한다**(2026-09-29 예행연습 발견). 설치기 사본(`_agent\setup\installer`)은 `checks` 단계만 만드는데 업데이트는 그 단계를 건너뛴다(`KEEP_DONE`). 그래서 `server.mjs` 업데이트 경로가 마무리 직전에 `copyInstallerProgram` 을 직접 불러 사본을 새 판으로 바꿔 끼운다(디스크에 영수증 파일이 있는 설치본에서만, 실패해도 업데이트는 끝남). 업그레이드 게이트 ③ⓙ 가 "사본 판 = 새 판, 사본에 `IRIS-삭제.cmd`"를 확인한다.
