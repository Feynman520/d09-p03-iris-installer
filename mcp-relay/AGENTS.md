# mcp-relay — IRIS MCP 중계기 원본

P03이 관리하는 MCP 중계기(안내원·공용 중계기·전환 도구)의 **원본**. 설치 사본(`<설치 폴더>\_agent\shared\tools\mcp-relay`)은 이 폴더로 만든 부품이므로 사본을 고쳐 원본처럼 쓰지 않는다. 설계 정본 = P03 `docs\설계-MCP중계기.md`.

- 파이썬 3.12 **표준 라이브러리만** 쓴다(동봉 런타임으로 돈다). 표준 출력에는 MCP 프로토콜만 쓴다.
- 시험은 `tests\`(`python -m unittest`) — 실제 사용자 설정을 건드리는 시험은 금지. 상태 폴더는 임시 폴더로, 설정은 임시 영혼 루트 안에만 둔다(2026-10-28 사고: 임시 상태의 공용 중계기가 실제 `CLAUDE_CONFIG_DIR`을 따라가 실제 설정을 바꿨다 — 바이트 단위 복구, `homes()`·`discover()` 범위 가드로 재발 방지).
