# 실행 검사소 — 화면 수용 조건 체크리스트 (v2, 8화면)

**무엇인가.** 설치기 v2(판 2.0.0)의 **화면 8장**이 실제로 사람이 쓸 수 있는 상태인지 눈으로 확인하는 표다. `docs/설계-v2.md` 4~8절(준비 검사표·질문 묶음·자동 단계·온라인·완료 보고 5순서)과 `docs/설치기-API-v2.md`(서버↔화면 계약)를 화면 쪽에서 되짚는다. 기계가 도는 층(1층 단위 시험 `node --test`, 2층 검사소 `verify/static.mjs`·`reproduce.mjs`)과 달리 **이 표는 사람이 돈다.**

> v1(1.x)판 체크리스트는 2026-09-15 이 문서로 대체됐다. 옛 6단계 화면(이름 입력·복사·넘기기)과 세팅가이드 관련 항목은 v2에서 사라졌으므로 그대로 옮기지 않았다. 옛 판이 필요하면 git 이력에서 꺼낸다.

## 두 가지 방법으로 돈다

| 방법 | 언제 | 무엇을 붙잡나 | 어떻게 |
|---|---|---|---|
| **ⓐ 가짜 서버 점검** | 화면을 고칠 때마다(몇 분) | 화면 자체의 흐름·문구·되돌아가기 | `node installer/ui/mock-server.mjs --port 3461` 로 띄우고 브라우저로 `http://127.0.0.1:3461/` |
| **ⓑ 진짜 설치 점검** | 배포 전(대상 PC에서 1회) | 진짜 서버·엔진과 맞물리는 부분 | 새 PC에서 zip을 풀고 `IRIS-설치.cmd` 두 번 클릭 |

가짜 서버(`installer/ui/mock-server.mjs`)는 **화면 확인 전용**이며 zip에 들어가지 않는다. 아무것도 설치하지 않고 127.0.0.1에만 귀를 연다. 상황을 골라 띄울 수 있다:

```text
--blockers      ① 준비 확인이 「막음」을 돌려준다
--foreign       ② 설치 위치에 남의 자료가 있다
--legacy        ② 1.x IRIS 자료가 있는 자리(이어 설치)
--fail venv     ⑥ 그 단계에서 설치가 멈춘다(오류 카드·다시 시도)
--login-reason window-closed|page-blocked|import-failed   ⑦ 로그인 실패 안내 3종
--reinstall     1.x 영수증을 자동 업데이트로 열었을 때의 카드
--speed 400     단계 하나에 걸리는 시간(밀리초)
```

## 사용법

- 위에서 아래로 순서대로 진행한다. 통과하면 `□`를 `■`로 바꾸고 시각·PC 식별(닉네임만, 실제 소유자명 금지)·비고를 옆에 적는다.
- 하나라도 실패하면 멈추고 `docs/검증기록.md`에 회차를 나눠 기록한 뒤 원본을 고치고 **처음부터 다시** 돈다(부분 재시험으로 통과 처리하지 않는다).
- ⓐ로만 확인할 수 있는 항목은 〔가짜〕, 진짜 설치가 필요한 항목은 〔진짜〕로 표시했다. 표시가 없으면 둘 다에서 본다.

## 0. 공통 — 모든 화면에서 늘 참이어야 하는 것

```text
□ 한 번에 카드 한 장만 보인다(한 화면 한 생각)
```
확인 방법: 각 화면에서 브라우저 개발자 도구 없이 눈으로, 제목 줄이 하나만 보이는지 본다. 위쪽에는 20칸 진행 막대 한 줄과 그 아래 "기준 = 끝난 화면 수 / 전체 8화면"이 늘 보인다.

```text
□ 화면 어디에도 중계 프로그램의 상표 이름("TeamClaude")이 0회
```
확인 방법: 여덟 화면을 모두 지나며 Ctrl+F로 찾는다. 계정을 잇는 일은 화면에서 **「계정 연결」**로만 부른다(⑥의 단계 이름 「중계기 준비」는 허용). 파일 검사로도 한 번 확인한다: `grep -c TeamClaude installer/ui/index.html` 가 0.

```text
□ 바깥에서 가져오는 것이 0건(글꼴·스크립트·그림)
```
확인 방법: 개발자 도구 네트워크 탭을 열고 화면을 처음부터 끝까지 돈다. `127.0.0.1` 밖으로 나가는 요청이 한 건도 없어야 한다. 인터넷 선을 뽑고 ①~⑥이 똑같이 보이는지도 함께 본다.

```text
□ 큰 글씨·한국어 문장, 선택형 질문 도구(라디오 묶음 등) 없이 평범한 단추와 번호 목록
```

```text
□ 새로고침(F5)해도 있던 자리로 돌아온다
```
확인 방법: ②④⑥⑦에서 각각 F5를 눌러, 서버가 들고 있는 `step`대로 같은 카드가 다시 뜨는지 본다(①로 되돌아가면 실패).

## 1. ① 준비 확인

```text
□ 열자마자 저절로 검사가 돌고, 막는 것이 0이면 사람 손 없이 ②로 넘어간다
```

```text
□ 막는 것(✗ 빨강 「막음」)·알아 둘 것(ⓘ 노랑)·괜찮은 것(✓)이 한 표에 섞여 보인다
```
확인 방법: 〔가짜〕 `--blockers`로 띄운다. 빨간 ✗ 줄에 "왜 막혔는지 + 무엇을 하면 되는지"가 한 문장으로 있고, 화면이 ②로 넘어가지 않으며 「다시 확인」 단추만 보이는지 확인한다.

```text
□ 「로그 경로 복사」를 누르면 경로가 복사되고, 복사가 막힌 브라우저에서는 경로를 화면에 보여 준다
```


```text
□ 영어 이름을 비우면 "영어 이름은 비서가 나중에 채울 수 있어요"가 그 줄 아래에 뜬다(오류가 아니다)
```

```text
□ 자리표시자 이름(기타·임시·테스트·test·temp·misc)을 적으면 그 자리에서 바로 빨갛게 막는다
```

```text
□ 오른쪽 미리보기가 R01-교사(Teacher) 꼴로 보이고, 영어를 비우면 R01-교사로 보인다
```

```text
□ 「나중에 비서와 정하기」를 누르면 미리보기가 R01-나(Me) 한 칸으로 바뀐다
```

```text
□ 서버가 되돌려준 오류(errors[])가 해당 줄에 빨갛게 표시된다
```


```text
□ 아홉 단계(풀기·환경변수·영혼 뼈대·작업 폴더·파이썬 환경·에이전트 연결·중계기 준비·목록 카드·검사)가 한국어로 보인다
```

```text

```

```text

```
확인 방법: 〔진짜〕 랜선을 뽑거나 와이파이를 끄고 ⑤에서 시작한다. ⑥이 모두 ✓가 된 뒤 ⑦에서 정직하게 멈추면 통과.

```text
□ 실패하면 오류 카드가 뜬다 — 오류 코드 · 쉬운 설명 · 「다시 시도」 · 「로그 경로 복사」
```

확인 방법: 〔가짜〕 `--fail venv`. 카드에 `E-VENV`와 "문서 도구만 못 쓰게 될 뿐 다른 것은 그대로입니다" 같은 쉬운 설명이 함께 있어야 한다.

```text
□ 「다시 시도」는 처음이 아니라 멈춘 단계부터 이어서 한다
```
확인 방법: 앞 단계의 ✓가 그대로 남은 채 실패한 줄부터 다시 도는지 본다.
